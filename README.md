# stanislas-sassolas.github.io

Personal portfolio of Stanislas Sassolas, data & AI engineer. Live at **https://stanislas-sassolas.github.io**.

A single static page, no build step:

- **Hero map**: a synthetic loss surface contoured in the browser with marching squares (index contours every 0.20, labelled like a printed topographic map), with gradient descent with momentum running on it. Click the map to start a new descent.
- **Project figures use real results**: the MeteoVelo hold-out week (hourly actual vs. predicted bike traffic), the confusion matrix of the COVID-19 sentiment model on its test set, and a live Ramer–Douglas–Peucker demo from the Duo app.
- English / Spanish, light / dark, responsive down to 360 px, `prefers-reduced-motion` respected.

Type: Bricolage Grotesque, Hanken Grotesk, JetBrains Mono (Google Fonts).
