LatAm Financial RAG

Personal project

A search and question-answering pipeline for Alicorp's financial reports, in Spanish. I combined keyword and semantic search, preserved table rows and added a reporting-period filter.

A reference page appears in the top six results for 29 of 32 answerable questions, compared with 25 for keyword search alone. This measures retrieval, not answer accuracy.

Python · BM25 + multilingual E5 · Claude API · PyMuPDF

MeteoVelo

Team of five

Predicting Lyon's hourly bike traffic from counter and weather data. I built the ML pipeline, from PySpark preparation to model comparison, then ran a separate chronological validation.

On the held-out week, R² was 0.95 and RMSE was 33% lower than the same-hour, previous-week baseline.

Python · PySpark · scikit-learn · Open data

PPO trading agents

Research project

I trained nine reinforcement-learning agents across Bitcoin, Ethereum and gold, using three seeds per asset, trading fees and chronological splits.

The average agent did not beat buy-and-hold on any of the three held-out test periods. Strong validation scores did not carry over to the test.

PyTorch · Stable-Baselines3 · Gymnasium
